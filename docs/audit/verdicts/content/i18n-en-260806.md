# English UI copy · en-GB · 2026-08-06

Статус **всех** ключей ниже — `draft`. До утверждения PO они блокируют клиентскую выдачу по `LOCALE-001`; наличие текста в этой таблице не означает `approved`.

Принцип имён: `nav`, `shell`, `common`, `origin`, `money`, `schedule`, `coverage`, `journal` — переиспользуемые сущности; `s1`…`s6` и `qa` — экраны; `analysis`, `offer` — общие крупные компоненты. Ключ описывает смысл, не текущую строку и не координату. `{name}` — именованный параметр, конструкции `{count, plural, …}` — целый ICU MessageFormat-ключ. Формат числа/валюты/даты задаёт реализация отдельно: деньги и проектные числа остаются в локали проекта; в тексте не хранится ни разделитель, ни пробел перед единицей.

В колонке «числовое?» `да` означает, что ключ получает число, процент, валюту, дату/время или счётчик и должен собираться форматтером, а не конкатенацией. Ограничения — редакционные бюджеты для текущего узкого места, включая пробелы; `нет` означает переносимый текст без жёсткого лимита.

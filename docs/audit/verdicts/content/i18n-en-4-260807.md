## Не переводится

После подключения поставки в золотом пути остаются две уникальные немецкие
строки из области текущего инвентаря:

| строка | причина |
|---|---|
| `Musterprojekt Nordfeld` | Значение фикстуры и имя проекта. Собственные имена не локализуются. |
| `Sehr geehrte Damen und Herren,\n\nanbei erhalten Sie unser indikatives Angebot für das Musterprojekt Nordfeld.\n\nMit freundlichen Grüßen` | Содержимое клиентского письма. Язык артефакта задаётся отдельно по D-13; при текущем `artifactLanguage=de` немецкое письмо в английском интерфейсе законно. |

Нормативные идентификаторы `WoFlV`, `DIN 276`, `MBO §2`, `GEG`, `KG 320`,
`GK 5`, `QNG` и `DGNB` сохраняются внутри английских предложений и не
считаются немецким fallback. `All3`, `Opportunities`, `Standard`, `Option`,
имена component API и клавиши уже не являются немецкими строками.

## Терминология и подключение

- `Risikozuschlag` → `risk allowance`; `Schätzunsicherheit` → `estimate uncertainty`;
- `Baugrundgutachten` → `ground investigation report`; `Tragwerk` → `structural works`;
- `Angebotssumme` → `offer total`; `Preiswirkung` → `price effect`;
- `Kundenansicht` → `client view`; `Komfortabel` → `Comfortable`, `Kompakt` → `Compact` как имена режимов;
- en-GB: `analysed`, `storeys`, `artefact` сохраняют британское написание.

Динамические сообщения с `{count}`, `{risk}`, `{name}`, `{filter}`, `{query}`,
`{value}`, `{time}` и `{snapshot}` должны подключаться как целые шаблоны.
Простой `translateText()` по уже собранной строке с фактическим значением их
не найдёт.

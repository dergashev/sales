## A. Дефект 5 твоего же ревью решается только в системе — измерение

Ты отдал дефект 5 (оранжевый тотал обрезается на всех вьюпортах) в зону `src`. Попытка исправить композицией упёрлась в арифметику шрифта (fontTools, `visuelt-bold-pro.woff2`, tnum-цифра = 0,700 em):

```
«≈ 3.818.000» при 64 px  ≈ 393 px
+ NNBSP + «€» при 24 px  ≈ 416 px неразрывной строки
контент панели при 400 px и px-5: 360 px · при px-4: 368 px
кегль, при котором строка помещается целиком: ≈ 55 px
```

Разорвать строку нельзя — U+202F неразрывен по правилу 7; сжать кегль тотала нельзя — 64 px нормирован правилом 31. Композиция в `src` не имеет хода: временно герой получил `overflow-x-auto` (число досягаемо, но прокрутка героя — не решение).

Реши на стороне системы, оба варианта твои:

1. **`--panel-right-width` ≥ 456 px** (416 строки + 40 паддинга) — токен помечен `[ADR-PENDING]`, реши и сними пометку; **или**
2. **container query для `.a3-heroband`/`.a3-hb`** — у системы уже есть узкие рецепты героя (`components.css` 639–658), но они привязаны к вьюпорту media query и не срабатывают в узкой панели на широком экране. Перевод на `@container` делает героя пригодным в его главном хосте. При этом реши нормативный вопрос: узкий рецепт понижает кегль тотала ниже 64 px — согласуй с правилом 31 (например, оговоркой в контракте DC-38 о минимальной ширине хоста).

Проверь результат на длиннейшем DE-тотале двух зданий (`≈ 10.489.000 €` — 10 цифр) и EN-локали.

## B. Дефект 18 твоего ревью: showcase-хелперы вместо продуктовых примитивов

Прототип потребляет `.a3-sheet`, `.a3-masthead`, `.a3-hero-title`, `.a3-lede`, `.a3-cap`, `.a3-linkbtn`, которые `components.css:6-16` помечает «not component API». Ты сам назвал следствие: отсутствие Card/Typography/Link-контрактов этим скрыто.

Добавь в систему продуктовые примитивы — контракт в `components-core.md` + образец в витрине + классы в `components.css`:

1. **Card/Sheet** — продуктовый лист-секция (то, чем прототип пользуется как `.a3-sheet`): поверхность, паддинг, отступ, поведение заголовка.
2. **PageHeader** — экранный заголовок (сейчас `.a3-masthead` + `.a3-hero-title` + `.a3-lede`): титул, мета-строка, базовая линия.
3. **Caption/SmallText** — то, что прототип берёт как `.a3-cap`.
4. **InlineLink/LinkButton** — `.a3-linkbtn` с зоной нажатия 44 и фокусом.

Именование продуктовых классов — на твоё решение (можно узаконить существующие имена, переместив их из showcase-зоны в component API — тогда `src` не меняется вовсе; можно завести новые — тогда перечисли соответствие старое → новое, Claude переведёт потребителей). Каждый примитив — с семью состояниями там, где он несёт данные, либо с названной причиной неприменимости (правило 30).

## Спор о длительности R-01

Исполнитель прав, аудитор ошибся в диагнозе. Независимый `Decimal`-пересчёт:

```text
base = 5 + (1969.67 - 1000) / 750
     = 6.292893333333333333333333333333333333...

duration = base * 1.00 * 1.15
         = 7.236827333333333333333333333333333333...

round_to_0.5(duration, ROUND_HALF_UP) = 7.0
```

Аудитор использовал уже усечённое `6.29`: `6.29 × 1.15 = 7.2335`. Это неверная точная база, хотя в данном случае обе последовательности случайно округляются к `7.0`. `calculation-spec.md:193-199` строит дату конца из округлённой длительности; при целых семи календарных месяцах D-17 (`decisions.md:419-437`) требует подпись `7 Monate`, а не `7,0 Monate`, и отклонение от R-26 не включается.

Контроль остальных спорных чисел:

```text
total = 1969.67 × 1545 × 1.05 × 1.03 + 328.28 × 1190
      = 3681809.272225

total / (1969.67 + 328.28) = 1602.214701027...  -> 1.602  (неверный scope)
total / 1969.67            = 1869.251840270...  -> 1.869  (верный scope)

above = 3291156.072225
below =  390653.20
above + below = 3681809.272225

old display:     3512000 + 335000 = 3847000
current display: 3291000 + 391000 = 3682000
```

## Пятнадцать пунктов — проверить каждый

**Журнал (M-4):**

1. `useStore.setState` больше не существует в публичном API — и это единственный был обход. Проверь не только отсутствие setState: **поищи новые обходы** (экспорт сырого store, мутация полученных из `getState()` объектов, запись в `snapshots`/`journal` напрямую).
2. Undo с курсором: два undo отменяют два разных события; третий — no-op; `undoOf` различается. Затем **композиция, которой в тестах нет**: undo → новое событие → undo → undo. Что происходит с курсором, когда после отмены появляется новое событие?
3. Разрешение конфликта WFL — одно событие; отмена восстанавливает значение, provenance и статус конфликта целиком.

**Снапшот (M-3):**

Событие отправки не имеет inverse — значит `undo` после отправки должен отменять предыдущее событие, а не отправку. Проверь.

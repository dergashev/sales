## Остаются БЕЗ значения — придумывать запрещено (R-25)

Блокируют одноимённые контракт-примитивы (перечислены на витрине Grundlagen):

- `--color-action-destructive-*` (4 шт.) — кандидат `#F04859` не проходит
  контраст 4,5:1; нужно решение по палитре опасного действия → Button
  destructive, Dialog подтверждения удаления.
- `--color-action-link-text` — цвет ссылки без оранжевого (R-01) → Link.
- `--color-surface-inverse`, `--size-tooltip-max-width` → Tooltip.
- `--size-control-indicator` (README называет 18px вне шкалы) →
  RadioCardGroup использует пока `--size-icon-lg`.
- `--size-slider-thumb-visual`, `--size-slider-track-thickness` → Slider.
- `--duration-toast-default` → Toast (не-undo).
- `--layer-presentation-banner` → баннер режима презентации.
- 34 записи разделов 1–3 (цвета/слои/движение с приближениями из
  бренд-гайда) — статус прежний, см. `adr-blocking.md`.

## Отклонение, о котором нужно знать

Витрина компонентов реализована **живой страницей Grundlagen (QA)** внутри
приложения, а не регенерацией статического `design-system/preview.html`.
Причина: живые компоненты не могут разойтись с кодом, статический HTML —
может (класс «одна сущность, два имени»). `preview.html` остаётся
историческим артефактом v1.0. Если нужен именно статический артефакт для
рассылки — скажите, соберу из тех же компонентов.

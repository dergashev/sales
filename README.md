# Indicative Offer Engine · прототип-симулятор

Из папки клиентской документации — индикативное коммерческое предложение. Прототип для теста с sales: **без LLM, без бэкенда, парсинг симулируется, арифметика настоящая**.

## Запуск

```bash
npm install
npm run dev          # http://localhost:5173
```

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | локальный сервер разработки |
| `npm run build` | продакшн-сборка в `dist/` |
| `npm run preview` | просмотр собранного |
| `npm test` | юнит-тесты движка расчёта |
| `npm run typecheck` | проверка типов без сборки |
| `npm run verify` | инварианты документации и сходимость фикстур |

Переменных окружения нет. Секретов нет. Внешних сервисов нет — это условие переносимости, а не упрощение.

## Что где

| Каталог | Содержимое |
|---|---|
| `src/engine/` | расчёт чистыми функциями, арифметика в Decimal |
| `src/fixtures/` | **выводится** из `docs/audit/synthetic-fixtures.md`, руками не править |
| `src/components/` | компоненты по контрактам `design-system/` |
| `design-system/` | токены, шрифты, контракты компонентов |
| `docs/product/` | продуктовая спецификация — источник истины |
| `docs/audit/` | ремедиация внешнего аудита, реестры требований |
| `tools/` | исполняемые проверки инвариантов |

## Три правила, которые ломаются молча

**Фикстуры не правятся руками.** Они выводятся скриптом: `python3 tools/build_fixtures.py`. Производные величины вычисляются в Decimal и сверяются с документом — 27 сверок. Рукописная правка заведёт второй источник правды, и он разойдётся с первым.

**Токены не копируются в `src`.** `src/styles/index.css` импортирует `design-system/tokens.css`. Копия — второй источник правды о цвете и размере.

**Произвольные значения в `className` запрещены.** Tailwind настроен **на токены**: дефолтная палитра и шкала недоступны вовсе, скругления, тени и градиенты отключены в конфиге. Если нужного токена нет — он добавляется в `tokens.css`, а не инлайнится.

## Проверка оснований

Первый экран показывает пять проверок, и каждая — дефект, который уже случался в проекте:

- три начертания Visuelt Pro доступны браузеру;
- `font-family` применён к `html`, `body` **и** элементам форм — однажды шрифт молча не подключился, потому что внешний reset объявил его прямо на `body`, и прямое объявление победило наследование;
- фон белый: акцентный оранжевый достигает порога контраста только на белом, на канве даёт 2,60:1 — дефект прожил четыре цикла аудита, потому что величину «3,10:1» никто не спросил «на какой подложке»;
- токены разрешаются;
- драйверы расчёта суммируются в итог, и открытый блокер закрывает все пять клиентских профилей.

Провал показывается видимо. Тихий провал повторил бы исходную ошибку.

## Перенос в продакшн

Прототип разворачивается локально; перенос выполняют девопсы All3 в своей среде. Условие переносимости: `npm install && npm run build` на чистой машине без правок. Абсолютных путей, секретов и зависимостей от внешнего окружения в репозитории нет.

Проверено на `node v24.18.0`, `npm 11.16.0`, macOS arm64.

Frozen composition

Three shells, one product family

Rails exist only when they carry decision value. Compare receives the whole width. Present removes operational machinery and retains one intentional progress strip.

WORK

  • 208 / flexible / 264 px at 1440
  • 190 / flexible / 226 px at 1280
  • Rail collapses when it has no meaningful content
  • Fixed action dock protects the next action

COMPARE

  • Both operational rails collapsed
  • 190–210 px sticky label column
  • Three options visible; fourth enters controlled overflow
  • Option heads and labels remain sticky

PRESENT

  • 64 px client-safe progress strip
  • No operational rails or preparation controls
  • Full-width stage per narrative beat
  • Viewed option switch never mutates the active work option

Design-owned choreography

Eight product edges, not generic animation

Durations are target ranges. Frontend owns browser integration, performance, interruption, cancellation, and fallback—not semantic sequence.

Accessibility evidence

Density does not trade away operability

Interaction

  • Minimum 44 × 44 px targets
  • 3 px high-contrast focus ring with offset
  • DOM focus order: global context → local navigation → heading → decisions → support rail → docked action
  • Tables, tabs, radio groups, fields, and disclosures retain semantic relationships

State

  • Status always uses icon + text, never colour alone
  • CompositionBar retains labels/legend
  • Incomplete and “nicht erfasst” remain textual
  • Calculation and delivery changes use an announced status region

Measured contrast

  • Ink / paper 12.82:1
  • Muted / paper 5.40:1
  • Ink / canvas 10.75:1
  • Ink / stage 11.12:1
  • White / stage-deep 16.48:1
  • Orange / stage-deep 5.32:1
  • Deep ink / orange action 5.32:1

Reduced motion

  • Meaning is preserved through immediate state replacement, stable anchors, focus movement, and textual status
  • No essential information exists only in transition
  • Count changes land on the final semantic value without interpolation

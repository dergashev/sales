## Accessibility evidence

- Minimum target size: 44 × 44 px.
- Visible focus intent: 3 px high-contrast ring with offset.
- Focus order: global context → local navigation → heading → decisions → meaningful rail → docked primary action.
- Statuses use icon and text; data graphics retain labels and legends.
- Reduced motion replaces choreography with immediate state clarity, focus movement, and announced status.
- Measured contrast: ink/paper 12.82:1; muted/paper 5.40:1; ink/canvas 10.75:1; ink/stage 11.12:1; white/stage-deep 16.48:1; orange/stage-deep 5.32:1; deep-ink/orange action 5.32:1.

## Downstream design acceptance instrument

Every downstream implementation task must compare:

CURRENT / BEFORE  
vs  
APPROVED VO-T1 TARGET  
vs  
IMPLEMENTED CANDIDATE  
vs  
RELEASED CURRENT_MAIN

A technically correct implementation is not sufficient. Design acceptance passes only if the released implementation materially reproduces the approved VO-T1 target and the visible transformation remains obvious in direct comparison. Any material reinterpretation of composition, hierarchy, media, spacing, rail behaviour, motion, or the Work/Compare/Present distinction requires a return to Design review.
